# Tide Docs V2

`docs_v2/` is the product-design workspace for Tide's next direction: a free, open-source Codex App alternative for local coding-agent work.

These docs are intentionally separate from `docs/`.

- `docs/` describes the current implementation and code-domain language.
- `docs_v2/` describes the new product, UX, and application model.

Do not share glossary ownership between the two folders. When a v2 product term maps to an existing implementation term, define that mapping in `docs_v2/glossary.md` instead of changing `docs/glossary.md`.
